# TaskFlow — REST API для управления задачами

TaskFlow — учебное REST API на FastAPI для создания, просмотра, обновления и удаления задач. Приложение поддерживает фильтрацию задач по статусу и приоритету, а также получение статистики.

## Возможности

- Создание задач с названием, описанием и приоритетом.
- Получение списка задач и просмотр задачи по ID.
- Фильтрация по статусу и приоритету.
- Обновление полей задачи.
- Удаление задач.
- Получение статистики по статусам задач.
- Проверка работоспособности приложения и получение информации о версии.
- Логирование запуска приложения и основных операций с задачами.
- Автоматические тесты и CI через GitHub Actions.

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/HoLuG/taskflow-api.git
cd taskflow-api
```

Создайте и активируйте виртуальное окружение.

**Windows PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
python -m pip install -r requirements_dev.txt
```

## Конфигурация

Настройки приложения задаются переменными окружения:

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| `APP_NAME` | `TaskFlow` | Название приложения |
| `APP_VERSION` | `1.0.0` | Версия приложения |
| `DEFAULT_TASK_PRIORITY` | `medium` | Приоритет новой задачи, если он не указан |

При использовании файла `.env` скопируйте пример:

```bash
cp .env.example .env
```

В Windows PowerShell:

```powershell
Copy-Item .env.example .env
```


## Запуск

Запустите приложение:

```bash
python -m uvicorn app:app
```

После запуска доступны:

- Приложение: http://127.0.0.1:8000
- Интерактивная документация API: http://127.0.0.1:8000/docs
- Альтернативная документация: http://127.0.0.1:8000/redoc

## API

| Метод | Маршрут | Описание |
|---|---|---|
| `GET` | `/` | Приветственное сообщение |
| `GET` | `/health` | Проверка работоспособности |
| `GET` | `/version` | Название и версия приложения |
| `POST` | `/tasks` | Создание задачи |
| `GET` | `/tasks` | Получение списка задач |
| `GET` | `/tasks/{task_id}` | Получение задачи по ID |
| `PATCH` | `/tasks/{task_id}` | Обновление задачи |
| `DELETE` | `/tasks/{task_id}` | Удаление задачи |
| `GET` | `/stats` | Статистика по статусам задач |

Допустимые приоритеты: `low`, `medium`, `high`.

Допустимые статусы: `todo`, `in_progress`, `done`.

### Пример создания задачи

Отправьте POST-запрос на `/tasks` с JSON-телом:

```json
{
  "title": "Изучить FastAPI",
  "description": "Реализовать и протестировать REST API",
  "priority": "high"
}
```

Пример с помощью curl:

```bash
curl -X POST http://127.0.0.1:8000/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"Изучить FastAPI","description":"Реализовать REST API","priority":"high"}'
```

### Примеры запросов

```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/version
curl http://127.0.0.1:8000/tasks
curl http://127.0.0.1:8000/tasks/1
curl http://127.0.0.1:8000/tasks?status=todo
curl http://127.0.0.1:8000/tasks?priority=high
curl http://127.0.0.1:8000/stats
```

## Тестирование

Запустите автоматические тесты:

```bash
python -m pytest -v
```

Тесты проверяют основные операции с задачами, валидацию входных данных, обработку отсутствующих задач, фильтрацию и статистику.

## Непрерывная интеграция

GitHub Actions запускает тесты при отправке изменений в репозиторий и при создании Pull Request в основную ветку. После успешного прохождения тестов workflow загружает артефакт приложения.

## Логирование

Приложение выводит сообщения о запуске, создании, обновлении и удалении задач. Логи доступны в консоли, в которой запущен Uvicorn.

## Ограничения

В текущей версии задачи хранятся в памяти процесса. Они не сохраняются после перезапуска приложения.
